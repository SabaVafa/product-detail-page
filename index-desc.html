Häufige Fragen

Kann ich mehr als eine Türstation anschließen (z. B. für einen Nebeneingang)?
Ja, es können mehrere Türstationen in das System integriert werden. Details finden Sie in der Anleitung Ihrer Anlage. Insgesamt können bis zu 16 Nebentürstationen pro Installation (=Haupttürstation) eingesetzt werden.
Gibt es Unterschiede bei der Bedienung der Innenstationen?
Nein, alle angebotenen Innenstationen bieten identischen Funktionsumfang. Lediglich die Innenstationen der Pro Serie bieten zusätzlich eine Türöffner Taste mit integrierter Beleuchtung.
Welche Kameras kann ich zusätzlich einbinden?
Alle HiLook by HIKVISION Kameras, welche Sie in unserem Überwachungskamera Bereich finden, können in das System eingebunden werden. Es können nur LAN/PoE Kameras eingebunden werden (Keine WiFi).
Sie kommen nicht weiter – gibt es persönliche Unterstützung?
Ja – buchen Sie einen persönlichen Online-Support-Termin mit unseren Sprechanlagen-Technikern: Sprechanlagen Online Support Termin
